# Book Door

Кинематика и интерактивная визуализация невидимой раздвижной двери
в книжном шкафу: две створки (А и Б) на жёсткой петле, движущиеся
по направляющей внутри проёма.

## Запуск

Открыть `door_sliding_viz_v12.html` в любом современном браузере.
Сервер и зависимости не нужны — это один самодостаточный HTML-файл.

## Параметры

| Параметр | Назначение |
|---|---|
| Ширина створки А / Б, мм | Габариты створок |
| Смещение оси 1 (створка А) / ось 3 (створка Б), мм | Позиция шарнира относительно торца |
| Толщина створок, мм | Толщина панели |
| Зазор проёма, мм | Чистый зазор (распределяется между стыками) |
| Число створок | 2 (А+Б) или 4 (зеркальные А и Б) |
| Длина стенок, мм | Длина стен проёма на схеме |
| Угол створки А, 0–180° | Положение механизма |

## Возможности

- **Кинематика**: точное положение створки Б для каждого угла А,
  включая контроль невозможного положения («Створка А слишком далеко»).
- **Коллизии**: детекция столкновений со стеной (по вершинам контура)
  и между створками (точный SAT по реальным контурам); красные ✕
  ставятся в центроид области пересечения.
- **Отладка**: оверлей границ проёма, min/max X створок — для
  верификации координат.
